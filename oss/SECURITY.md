# Security Policy

## Reporting a vulnerability

Use GitHub private vulnerability reporting
with what you found
and how to reproduce it.
We accept reports
in English or Japanese.

Do not open a public issue
for a vulnerability.
Do not post secrets, tokens,
or production identifiers
in public issues.

## What to include

- The panel version note
  (`umeboshi-ask:panel-version`).
- The Worker URL type
  (official or self-hosted).
  Never paste the access token.
- Steps to reproduce.
- What you expected
  and what happened.
